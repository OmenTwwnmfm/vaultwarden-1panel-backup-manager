# 支持矩阵

## 运行要求（硬性）

| 项目 | 要求 |
|---|---|
| 操作系统 | Ubuntu / Debian（使用 systemd） |
| 部署方式 | 1Panel 应用商店、docker compose 或 docker run |
| Vaultwarden | 官方 `vaultwarden/server` Docker 镜像 |
| 数据库 | SQLite |
| 容器数据路径 | 容器内 `/data` 挂载到主机目录（bind mount）或 Docker 命名卷 |
| 权限 | root，或可通过 sudo 管理 Docker、systemd 和系统目录 |
| 远端 | 独立 GitHub Private 备份仓库或 WebDAV HTTPS 专用目录 |

不支持：MySQL / PostgreSQL 外部数据库、容器内非 `/data` 的自定义数据布局（含修改 `DATA_FOLDER`）、非 Docker 的二进制 / systemd 直装、Podman、非 systemd 发行版。
