# 恢复演练记录模板

备份是否可信，只能由真实恢复演练证明。本文件是空白模板：每完成一次真实演练，复制下方「演练记录」一节另存或追加一份并如实填写；不要把预期结果写成实测结果。

演练方式任选其一（见完整使用手册）：

- `[05]` 解密校验：在 `/dev/shm` tmpfs 解密并检查历史备份，不修改生产数据。
- `[09]` 容器演练：在 `/dev/shm` tmpfs 解密，用无网络、无端口映射的临时容器演练恢复并检查能否启动。

安全提醒：记录中不要写 age 私钥、用户主密码、Token 或数据库内容；备份文件名和校验值可以记录。
