## 恢复时必须确认

- [ ] 已取得对应的 age 私钥离线副本。
- [ ] 新 VPS 已安装并启动 Docker（1Panel 管理或独立安装）。
- [ ] 新 VPS 已用原部署方式创建兼容版本的 Vaultwarden 容器。
- [ ] 新容器的 `/data` 挂载目录已确认。
- [ ] 使用创建旧备份时的 age 公钥配置管理器。
- [ ] 新 VPS 已配置 GitHub Deploy Key 权限。
- [ ] 恢复后检查登录、密码库、附件、TOTP 和客户端同步。
- [ ] 用户主密码及 MFA 恢复码由用户自行掌握。
